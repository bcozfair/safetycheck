# 🦺 SafetyCheck — ระบบตรวจการสวมเสื้อสะท้อนแสงก่อนเข้าพื้นที่

ระบบตรวจสอบอุปกรณ์ป้องกันส่วนบุคคล (PPE) ด้วย AI จำแนกภาพ
สร้างด้วย [Google Teachable Machine](https://teachablemachine.withgoogle.com/) + TensorFlow.js
ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์

> วิชา SCS 352 — Emerging Technologies

---

## ปัญหาที่แก้

ในไซต์งานก่อสร้างและโรงงาน การไม่สวมเสื้อสะท้อนแสงเป็นสาเหตุอุบัติเหตุจากการถูกยานพาหนะเฉี่ยวชน
แต่การตรวจสอบต้องใช้เจ้าหน้าที่ความปลอดภัยยืนเฝ้าที่ทางเข้าตลอดเวลา ซึ่งทำได้ไม่ทั่วถึง
และไม่มีข้อมูลสถิติว่าการละเลยเกิดบ่อยแค่ไหน ช่วงเวลาใด

ระบบนี้ทำหน้าที่ **เตือนก่อนเข้าพื้นที่ + เก็บสถิติ** เพื่อให้เจ้าหน้าที่ความปลอดภัยเห็นภาพรวมและวางแผนแก้ปัญหาได้

---

## วิธีใช้

เปิดผ่าน **HTTPS** หรือ **localhost** เท่านั้น (ข้อบังคับของเบราว์เซอร์ในการเข้าถึงกล้อง)

```bash
python -m http.server 8000
```

แล้วเปิด <http://localhost:8000>

1. กด **เริ่มตรวจ** เพื่อเปิดกล้อง
2. ยืนบนจุดตรวจ ให้เห็นตั้งแต่หัวถึงเอว
3. รอให้แถบสีฟ้าด้านบนวิ่งจนครบ ระบบจะตัดสินผล
4. 🟢 ผ่าน = เข้าพื้นที่ได้ / 🔴 ไม่ผ่าน = มีเสียงเตือนและแจ้งว่าขาดอะไร

กด **Space** เพื่อข้ามช่วงพัก ไปตรวจคนถัดไปทันที

---

## กลไกที่ทำให้ใช้งานได้จริง

ผลลัพธ์ดิบจากโมเดลจำแนกภาพนำมาใช้ตรงๆ ไม่ได้ เพราะจะสั่นและตัดสินผิดตลอดเวลา
ระบบจึงมีตรรกะ 3 ชั้นก่อนตัดสิน

| กลไก | ค่าเริ่มต้น | แก้ปัญหาอะไร |
|---|---|---|
| **Confidence threshold** | 85% | ถ้าโมเดลไม่มั่นใจพอ จะขึ้น "ยังไม่ชัด" แทนการเดามั่ว |
| **Dwell time** | 2 วินาที | ต้องเห็นผลเดิมนิ่งต่อเนื่อง กันผลกระพริบตอนคนเดินผ่าน |
| **Cooldown** | 4 วินาที | กันการนับซ้ำ เพราะกล้องทำงาน ~30 เฟรม/วินาที |

ปรับค่า threshold และ dwell time ได้จากหน้าเว็บโดยตรง

## ฟีเจอร์

- ตรวจแบบเรียลไทม์ผ่านเว็บแคม พร้อมกรอบเปลี่ยนสีให้เห็นผลจากระยะไกล
- แจ้งเตือนด้วยเสียงพูดภาษาไทย และเสียงบี๊บเมื่อไม่ผ่าน
- ทดสอบด้วยรูปภาพได้ (ลากวาง / Ctrl+V / เลือกไฟล์)
- บันทึกประวัติการตรวจลง `localStorage` เก็บได้ 500 รายการล่าสุด ไม่หายเมื่อรีเฟรช
- สรุปสถิติ ผ่าน / ไม่ผ่าน / อัตราผ่าน
- ส่งออกเป็น CSV เพื่อทำรายงาน

---

## ความเป็นส่วนตัว

**ภาพจากกล้องไม่เคยถูกส่งออกจากเครื่อง** — โมเดลถูกดาวน์โหลดมาประมวลผลในเบราว์เซอร์ทั้งหมด
ไม่มีการอัปโหลดภาพขึ้นเซิร์ฟเวอร์ใดๆ และประวัติการตรวจเก็บอยู่ในเครื่องนั้นเครื่องเดียว
เป็นข้อได้เปรียบด้าน PDPA เมื่อเทียบกับระบบ CCTV ที่ส่งภาพขึ้นคลาวด์

---

## ข้อจำกัด

ระบบนี้เป็น **เครื่องช่วยเตือนและเก็บสถิติ ไม่ใช่ด่านความปลอดภัยด่านเดียว**
ควรมีเจ้าหน้าที่ความปลอดภัยกำกับเสมอ

- โมเดลปัจจุบันเทรนไว้ 2 คลาส (`yes` / `no`) **ยังไม่มีคลาส "ไม่มีคน"** ทำให้เมื่อไม่มีใครยืนหน้ากล้อง
  ระบบยังถูกบังคับให้เลือกคำตอบอยู่ดี — บรรเทาด้วย threshold และ dwell time แต่วิธีแก้ที่ต้นเหตุคือเพิ่มคลาสที่ 3 แล้วเทรนใหม่
- ตรวจได้เฉพาะเสื้อสะท้อนแสง ยังไม่ครอบคลุมหมวกนิรภัย แว่นนิรภัย ถุงมือ รองเท้าเซฟตี้
- ความแม่นยำขึ้นกับมุมกล้องและแสง ควรเทรนจากมุมกล้องเดียวกับที่ติดตั้งจริง
- หลบเลี่ยงได้ด้วยการสวมตอนสแกนแล้วถอดหลังผ่านประตู
- **ต้องมีอินเทอร์เน็ต** เพราะโหลดไลบรารีจาก CDN และโมเดลจากเซิร์ฟเวอร์ Teachable Machine

---

## แนวทางพัฒนาต่อ

- เพิ่มคลาส `ไม่มีคน` เพื่อลดการตัดสินผิดเมื่อพื้นที่ว่าง
- เพิ่มตัวอย่างลวง (สวมเสื้อยืดสีส้มที่ไม่มีแถบสะท้อนแสง, พาดเสื้อกั๊กบนไหล่) เข้าคลาส `no`
- แยกเป็นหลายโมเดลอิสระ เพื่อตรวจ PPE หลายชิ้นพร้อมกันเป็น checklist
- ดาวน์โหลดโมเดลมาเก็บในโปรเจกต์ ให้ทำงานแบบออฟไลน์ได้
